# 🏠 Custom Browser Homepage

A Custom-Browser-Homepage catering to both performance and privacy.

## 🚀 Deploy & Set as Homepage

This project is meant to be **your new homepage** — easy to use, deploy, and personalize.

### 🌍 Option 1: Use the Live Version

You can use the live version directly (if hosted):

```txt
https://privatehomepage.netlify.app/
```

To set it as your homepage:

1. **Chrome**:
   `Settings → On Startup → Open a specific page → Add a new page → Paste the link above`
2. **Firefox**:
   `Settings → Home → Homepage and new windows → Custom URLs → Paste the link`
3. **Edge**:
   `Settings → Start, home, and new tabs → Open these pages → Add a new page`

---

### 💾 Option 2: Deploy Your Own

1. **Fork this repo** or download it.
2. If using GitHub:

   * Push to a public repo.
   * Enable GitHub Pages from repo settings:

     * Source: `main` branch (or whichever you use)
     * Path: `/ (root)`
   * Use the provided GitHub Pages URL as your homepage.
3. If using local files:

   * Open `index.html` in your browser.
   * Set the `file://...` path as your homepage (varies by browser).

---

### 🛠 Customize It

* Edit `style.css` or `index.html` to suit your needs.
* Add your own links, widgets, or visuals.
